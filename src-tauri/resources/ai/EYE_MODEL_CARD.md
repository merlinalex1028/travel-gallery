# 闭眼提示模型与使用范围

MediaPipe Face Landmarker V1：BlazeFace Short Range → Face Mesh V2 → Blendshape V2，固定权重 SHA-256 64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff。

此模型原本面向近距离人脸与表情效果。旅图仅将其用于可忽略的照片检查提示，不做人物识别，不关联不同照片中的人物，不保存完整脸部关键点。模型输出不是闭眼概率。

每张预览最多处理 10 张人脸；到达上限会提示。未检出、过小、裁切或明显侧脸均不能据此判断眼睛睁闭。远景、眼镜、遮挡、头部姿态和预览分辨率均可能漏报或误报；“未发现明显提示”不保证所有人睁眼。

当前规则将双眼几何开合比 ≤0.16 且两个 eyeBlink 系数 ≥0.35 的人脸列为“可能闭眼”；明显不对称的单眼情况可提示眨眼。规则用于人工复核，尚未通过大规模人类标注校准，不用于自动淘汰或修改星级。

权重与作者说明卡独立离线导入，默认关闭。推理使用独立 Rust CPU 进程，1 线程，约 60 秒空闲后退出。关闭会停止对应分析任务并释放进程。应用无模型下载或遥测客户端，不打包 MediaPipe Python/原生 SDK。
