The Travel Gallery guide

From adding your first photo folder to organizing and sharing a journey. Find everyday instructions right here.

Quick start

  1. Choose the installer for your computer, install it and open Travel Gallery.
  2. Click Add photo folder and authorize a local or external-drive folder using the system picker. Choose subfolders, hidden-file handling and exclusion patterns.
  3. Let the background index and thumbnails build, then filter the library or flag photos in the Culling desk.
  4. Create a trip album and select photos in the library to Add to trip. Preview before copying exports to share.

The app references original photos and videos without moving them. Browser interactions use built-in demo media only.

Installation and first launch

Platform Installation Requirements
macOS Apple Silicon Open the DMG, drag Travel Gallery into Applications, then launch it from there. macOS 13+, Apple Silicon
Windows x64 Run the EXE and follow the installer. An offline WebView2 installer is included. Windows 10 / 11, 64-bit

Current macOS builds use ad-hoc integrity signing without Apple notarization. Windows builds have no Authenticode signature. Update archives have separate integrity signatures; neither is a system-trusted publisher signature.

  1. Use the GitHub Release installers linked from this website and verify the matching SHA256SUMS.txt.
  2. If macOS blocks launch, check System Settings → Privacy & Security for Open Anyway.
  3. If Windows shows SmartScreen, look for More info → Run anyway. Organization policies may prevent manual approval.

You do not need to disable global system security. Verify checksums with:

shasum -a 256 Travel-Gallery-*-macOS-arm64.dmg
Get-FileHash .\Travel-Gallery-*-Windows-x64-setup.exe -Algorithm SHA256

Back up originals and the catalog before installing over an older version. Upgrades keep the production catalog.

Features and shortcuts

  • Library: browse photos and videos together. Combine filename, folder, time, format, tag and rating filters, then save a smart filter.
  • Culling: keep, maybe, reject, ratings, favorites and notes. Undo changes and compare 2–4 photos with synced zoom. Rejection sets a flag only.
  • Duplicates and similarity: separate SHA-256 exact duplicates, visually similar groups and time-based bursts for manual review.
  • Trips: albums across sources, timelines, offline GPS maps and travel stories. Unknown capture dates and time zones are clearly marked.
  • Sources: manage offline, missing and limited formats. Rescan after reconnecting drives. Verified relocation can restore source associations.

Live Photo pairing and playback

Among unmodified originals exported by Apple Photos, JPG / JPEG / HEIC / HEIF and MOV pair automatically when their Apple content identifiers match uniquely. Merge companions is on by default and shows a single LIVE · 2 card.

Matching filenames in the same folder without valid content identifiers are candidates. Review them in Photo details → Companion media → Confirm pairing. Hover over LIVE in the top-left corner of the viewer to play silently once. Leaving stops playback; re-enter to play again. Enter / Space or tapping also works.

This is a companion MOV preview subject to local decoding support, without Apple's native press-and-transition effects. Changing photos or closing the viewer stops playback. Originals remain separate.

Apple-exported XMP is not used for pairing; its IPTC content is not currently imported. Travel Gallery can separately generate tags, ratings and notes as XMP when exporting.

Copy and story exports

Select photos, choose Copy export, then choose a folder, layout, collision rule and optional XMP or confirmed companion files. Preview counts, size, collisions and source status before confirming. Preview paths use / consistently.

Media and XMP are written to temporary copies and SHA-256 verified before publication. Existing files are never overwritten. Directories are protected against substitution. Failures clean only this operation's temporary files with matching identities. Completed copies remain; see Jobs → Export report for results.

Travel stories can export offline HTML, JPEG previews and a SHA-256 manifest for up to 5,000 items. Videos use still frames; originals are excluded. Notes are opt-in. Re-encoded previews omit GPS fields and source folder paths. Share the entire story folder.

In-app updates

  1. Open Settings → App updates → Check for updates.
  2. If an update is found, click Download update to see progress. Its signature is verified after downloading.
  3. Save edits and finish or cancel all background tasks, including paused ones, then confirm Install and restart.

Automatic checks are off by default. When enabled, they run at startup and every 4 hours, only notifying you. Downloads and installation remain manual. Updates follow the latest stable release; download prereleases manually.

Checks and downloads connect to GitHub and its asset services without sending photos, paths or catalog contents. Offline use does not affect browsing and organization. Downloads last for this process only. Missing manifests, network or installation failures show an error. Retry or install manually.

Supports macOS Apple Silicon and Windows x64 release packages. Browser demos, development and audit builds do not check or install. On macOS move the app into Applications first. Older versions without the update setting need a manual installation first.

Catalog, cache and privacy

Use Settings → Local catalog to back up or restore indexes, ratings, tags, albums and tasks. Backups are verified and the current catalog is backed up before restoring. Originals and separate model packages are not included; back them up separately.

Clearing cache removes only regenerable previews, preserving organization records. Offline sources retain thumbnails and review results without the entire drive being misclassified as missing.

Core browsing and organization run locally, with no account, photo uploads or telemetry. The offline map uses public-domain Natural Earth data and never requests coordinates online. The website has no analytics scripts or third-party fonts.

Optional local analysis

Local AI and closed-eye hints are off by default. Import a separate offline model package and enable it yourself. Models are not downloaded automatically and photos are not uploaded. Pause or cancel in Jobs; disabling analysis releases inference processes.

AI content search and grouping, eye hints and same-scene detail measurements are for human review only. They never reject photos or change ratings automatically. Models and indexes can be removed and rebuilt; manual organization is preserved.

Development and builds

The frontend uses Vue 3, TypeScript, Pinia and Element Plus; the native app uses Rust, Tauri 2 and SQLite. The website is independent static HTML. Requires Node.js 22, pnpm 10, Rust stable and Tauri platform prerequisites. 

pnpm install --frozen-lockfile
pnpm dev          # Browser demo
pnpm desktop      # Isolated native development
pnpm test
pnpm build
pnpm test:rust
pnpm site:build

Native development uses com.travelgallery.development; production uses com.travelgallery.desktop. Tests use owned temporary media and isolated catalogs to protect originals.
