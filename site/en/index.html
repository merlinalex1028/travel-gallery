How do I check for and install updates?

Open Settings → App updates → Check for updates. When a new version is found, choose Download update to see progress. After signature verification, confirm Install and restart. Save edits and finish or cancel all background tasks, including paused ones. Updates preserve the catalog and originals; retry failures or install manually from the website. Automatic checks are off by default and save immediately. When enabled they run at startup and every 4 hours; you control downloads and installation. Requests go to GitHub and its asset services, without photos, paths or catalog contents. Downloads last for the current process only. Supports macOS Apple Silicon and Windows x64 release builds and follows the latest stable release. Download prereleases manually. On macOS move the app to Applications first. Update signatures do not replace OS publisher signatures or permissions. Browser demos, development and audit builds do not check or install. Older apps without this setting need a manual installation first. Publishers must configure update signing and publish the manifest; missing manifests or network failures show an error.

How are exported Apple Live Photos displayed?

JPG / JPEG / HEIC / HEIF and MOV files pair automatically when Apple content identifiers match uniquely. Merge companions is on by default and shows a LIVE · 2 card. Matching filenames alone need confirmation in Photo details → Companion media. Hover over the small LIVE badge at the top left of the viewer to play silently once. Leaving stops playback and restores the still photo; hover again to replay. Enter / Space or a tap also works. Changing photos or closing the viewer stops playback. Retry decoding failures or open the MOV in the system app. This previews the companion video, without Apple's native press-and-transition effects. Originals stay separate. XMP is not used for pairing and its IPTC data is not currently imported. Exports can include confirmed companion files and separately generated tags, ratings and notes as XMP.

Will Travel Gallery move or delete my originals?

Adding a source creates an index; originals stay in place. Culling updates local records only. Copy exports are previewed first; duplicate or AI results never delete originals automatically. Export previews use / for relative paths. Photos, videos and XMP are written to temporary copies and verified before publication. Existing files are preserved on collisions. Directories are protected against substitution. Failures clean only temporary files created by this operation whose identity still matches.

Can I use it without an internet connection?

Core desktop features work locally without a cloud account. Download the app and any optional models in advance. This website is hosted on GitHub Pages and needs a connection. App updates are optional, with automatic checks off by default. Offline use does not affect core browsing and organization.

Why does the first launch show a security warning?

macOS builds use ad-hoc integrity signing without Apple notarization; Windows builds have no Authenticode signature. Download from this repository's releases and verify SHA-256. Organization-managed devices may not allow manual approval. See the installation guide for steps.

Does a catalog backup also back up my photos?

No. Catalog backups contain indexes and organization records, not original photos, videos or separate model packages. Back up your original media separately.
